## Selected projects

### Tromatic NEXT · Industrial monitoring & control

A mobile and web platform connecting industrial wood-drying installations to live sensor data, historical charts and customer administration.

- **Product:** iOS and Android monitoring of chamber conditions, alarms and supported machine controls, with a web administration portal.
- **Engineering:** React Native and Expo clients, a Next.js portal, Firebase services and a Node.js integration with on-site Windows systems.
- **Portfolio focus:** the repository documents the architecture and telemetry flow between machinery, cloud services and the user interface.

**React Native · Expo · Next.js · Firebase · Node.js · Redux Toolkit**

[Source & architecture](https://github.com/Rubinjo/Tromatic-Next-App) &nbsp;·&nbsp; [App Store](https://apps.apple.com/us/app/tromatic-next/id6476465551) &nbsp;·&nbsp; [Google Play](https://play.google.com/store/apps/details?id=nl.besbollmann.tromaticnext)

## Research

**Co-author · Journal of Breath Research · 2025**

[Overcoming methodological barriers in electronic nose clinical studies, a simulation data-based approach](https://doi.org/10.1088/1752-7163/add291)

Research into how disease prevalence, data augmentation and device variability affect the data needed for reliable electronic-nose prediction models. The study used simulated breath-test data grounded in real-world measurements and evaluated random forest and convolutional neural network approaches.
